AI Provider

Choose which AI provider to use for summarization. Each requires its own API key.

OpenAI defaults: gpt-4o-mini (fast) or gpt-4o (higher quality)

API Key

Your API key is stored locally in Chrome's encrypted sync storage and never sent anywhere except to the AI provider when you summarize a page.

Get your key from OpenAI Platform Google AI Studio

Security

  • API keys are stored in chrome.storage.sync — encrypted by Chrome.
  • Keys are only sent to the selected AI provider from the background service worker.
  • Keys are never injected into page content scripts.
  • All summaries are cached locally and expire after 30 minutes.

Cache

Summaries are cached for 30 minutes to avoid redundant API calls.
