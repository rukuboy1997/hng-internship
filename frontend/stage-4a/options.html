Extension Settings

Powered by Gemini

  • This extension uses Google Gemini 2.5 Flash via a secure proxy server.
  • No API key is required — everything is handled automatically.
  • Page content is sent to the proxy, which calls Gemini and returns your summary.
  • Summaries are cached locally for 30 minutes to avoid redundant calls.
